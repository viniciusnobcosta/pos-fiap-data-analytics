# Tech Challenges | Data Analytics — FIAP

Repositório destinado ao desenvolvimento e à documentação dos projetos realizados durante a pós-graduação em **Data Analytics da FIAP**, reunindo análises, estudos, aplicações práticas e soluções orientadas a dados.

Os Tech Challenges têm como objetivo aplicar os conhecimentos adquiridos ao longo da formação, utilizando conceitos, metodologias e ferramentas de Data Analytics para solucionar problemas e gerar insights relevantes para o negócio.

---

## Sobre o repositório

Este repositório reúne os projetos desenvolvidos pelo Grupo 7 ao longo dos Tech Challenges da pós-graduação.

Cada projeto possui uma pasta específica, contendo seus respectivos códigos, notebooks, documentação, bases de dados (quando permitido) e demais materiais necessários para apresentar o desenvolvimento e os resultados das análises.

## Tecnologias e ferramentas

As tecnologias utilizadas poderão variar de acordo com os objetivos e requisitos de cada desafio.

Entre as principais ferramentas e tecnologias utilizadas estão:

- **Python:** análise, tratamento e processamento de dados;
- **Pandas e NumPy:** manipulação e análise de dados;
- **Matplotlib e Seaborn:** visualização de dados;
- **SQL:** consultas e manipulação de bancos de dados;
- **Power BI:** construção de dashboards e relatórios analíticos;
- **Jupyter Notebook:** desenvolvimento de análises interativas;
- **Git e GitHub:** versionamento e colaboração.

---

## Metodologias

Os projetos poderão utilizar metodologias e abordagens analíticas de acordo com suas necessidades, incluindo:

- **CRISP-DM:** metodologia para estruturação de projetos de Data Analytics e Data Mining;
- **Análise Exploratória de Dados (EDA):** investigação inicial das bases de dados;
- **Estatística Aplicada:** utilização de conceitos estatísticos para interpretação e avaliação dos dados;
- **Data Storytelling:** comunicação dos resultados por meio de narrativas orientadas a dados.
